UNICOnNECT PROTOTYPE
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Select a role on the login screen and sign in.
4. Explore the sidebar modules. Forms and interactions are simulated in the browser.
5. To publish: upload index.html to a GitHub repository and enable GitHub Pages (Settings > Pages > Deploy from branch > main > /root). The published GitHub Pages URL can then be pasted into the assignment report.

IMPORTANT LIMITATIONS
This is a front-end academic prototype. It uses sample data and simulated login/payment/integrations. It does not provide production authentication, database persistence, real payment processing, biometric connectivity, Moodle APIs, scholarship APIs, or placement APIs. A production system needs a secure backend, database, role-based authorization, validation, API credentials, audit logs, and privacy controls.
