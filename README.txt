UNICONNECT – FULL CASE STUDY PROTOTYPE

Run locally:
1. Extract this ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Select Student, Faculty, Parent, or Administrator and sign in with sample details.
4. Explore the navigation items available for that role.

Case-study coverage:
- Student and faculty login and dashboards
- Student registration/profile/admission/academic history (sample profile)
- Faculty profile, subject allocation, workload, attendance entry, marks entry, announcements and assignment upload interface
- Attendance calculation display, low-attendance alert and condonation request
- Elective and interdisciplinary course registration with credit total
- Examination schedules, marks/results
- Fee details, payment records and simulated receipt/payment actions
- Timetable and classroom allocation
- Parent dashboard
- Grievance submission and tracking reference
- Notifications and announcements
- Administrator user management, reports and department policy controls
- Proposed external integration points: payment, biometric, Moodle/LMS, scholarship and placement platforms
- Incremental release/feedback log illustrating faster delivery

IMPORTANT:
This is an academic front-end prototype with illustrative sample data. Login is simulated role selection, not secure authentication. Form submissions and settings are not persisted to a backend database. Payment, biometric, Moodle, scholarship and placement integrations are not live. Assignment upload is a demonstration interface, not permanent file storage. A production implementation requires a secure backend, database, authentication, authorization, audit logging, data protection, and verified API integrations.
